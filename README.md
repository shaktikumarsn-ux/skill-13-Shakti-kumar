# SHAKTI SKILL 13: anime-reel

Is folder mein sab kuch hai:

| Folder / file | Kya hai |
|---|---|
| `INSTALL.command` | Double-click karo: skill aapke Mac par Claude Code mein install ho jaayegi |
| `skills/anime-reel/` | Poori skill (SKILL.md, scripts, renderer, fonts, Munni-Pintu preset) |
| `episodes/munni_pintu/videos/` | Teeno final videos: reel 9:16, YouTube 16:9, WhatsApp 720p |
| `episodes/munni_pintu/character_sheets/` | Munni aur Pintu ke character sheets |
| `episodes/munni_pintu/contact_sheets/` | Stills (9:16 aur 16:9) |
| `episodes/munni_pintu/episode.json` | Episode ka shot list (dobara banane ke liye) |
| `episodes/munni_pintu/voice/` | Original voice MP3 |

## Mac par install
1. `INSTALL.command` par **double-click** karo.
   - Agar Mac bole "can't be opened": file par **right-click → Open → Open** karo.
2. Claude app mein **Code** kholo (local session, koi bhi folder) aur likho:
   ```
   /anime-reel
   ```
   Saath mein script paste karo aur voice MP3 attach karo (har line ki alag MP3, ya poori baatchit ki ek MP3).

## GitHub par daalna ho
Repo mein pehle `.claude/skills/README.md` naam se ek file banao (GitHub → *creating a new file*),
phir repo mein `.claude/skills` folder kholo → **Add file → Upload files** → `skills/anime-reel` folder drag karo → **Commit**.
